# Vercel backend service requirements (service root: quant-app-v1/backend/).
#
# This is intentionally a TRIMMED subset of the repo-root requirements.txt
# (Docker/CI source of truth), because Vercel's Python function bundle limit
# is 500MB uncompressed and the full set (llvmlite/numba/scipy + sklearn +
# skfolio/plotly + ccxt + ...) exceeded it. Only packages actually imported
# by app/ at runtime are kept; everything below has zero import sites or is
# wrapped in try/except and degrades gracefully when absent.
#
# Vercel's parser rejects '-r' includes and inline comments after pins, so
# every comment sits on its own line.
#
# Divergences from the root requirements.txt (keep root intact for Docker/CI):
#   DROPPED (unused or lazy+guarded in app/):
#     Flask, flask_session      — no import sites in app/
#     scikit-learn, skfolio     — no import sites in app/ (skfolio pulls
#                                 plotly/cvxpy/highspy ~60MB)
#     ccxt (~36MB)              — lazy import in providers/ccxt_provider.py;
#                                 is_configured/backup paths catch ImportError
#     fastapi-utils, finnhub-python, beautifulsoup4, textblob, vaderSentiment
#                               — no import sites in app/
#     psycopg2-binary, redis    — no import sites in app/ (Supabase via httpx)
#     pytest, pytest-asyncio    — tests/ is excluded from the deploy
#   KEPT: statsmodels for rolling Engle-Granger pair cointegration tests.
#   pandas-ta was removed after replacing its RSI calls with the local
#   pandas-based Wilder implementation, eliminating numba/llvmlite from
#   the deploy dependency chain.
